# 🐍 Python Operators

This folder contains my practice and implementation of different types of operators in Python.

## 📚 Topics Covered

### 1. Arithmetic Operators

Used to perform mathematical operations.

* Addition `+`
* Subtraction `-`
* Multiplication `*`
* Division `/`
* Floor Division `//`
* Modulus `%`
* Exponentiation `**`

### 2. Assignment Operators

Used to assign and update values.

* `=`
* `+=`
* `-=`
* `*=`
* `/=`
* `//=`
* `%=`
* `**=`

### 3. Comparison Operators

Used to compare two values.

* `==`
* `!=`
* `>`
* `<`
* `>=`
* `<=`

### 4. Logical Operators

Used to combine or reverse conditions.

* `and`
* `or`
* `not`

### 5. Identity Operators

Used to check whether two variables refer to the same object.

* `is`
* `is not`

### 6. Membership Operators

Used to check whether a value exists in a sequence.

* `in`
* `not in`

### 7. Bitwise Operators

Used to perform operations at the binary level.

* `&` AND
* `|` OR
* `^` XOR
* `~` NOT
* `<<` Left Shift
* `>>` Right Shift

## 🎯 Learning Goals

* Performing mathematical calculations
